2. Running Everything Locally
2.1 Start All Services — Step by Step
Open 4 separate terminal windows. Run one command in each:

Terminal 1 — Start Databases (PostgreSQL + Redis + ChromaDB):
cd mirrormind
docker-compose up -d
# Verify running: docker ps

Terminal 2 — Start Python AI Service:
cd mirrormind/ai-service
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Terminal 3 — Start Node.js Backend:
cd mirrormind/backend
npm run dev
# This starts Express on port 4000 with hot-reload

Terminal 4 — Start Next.js Frontend:
cd mirrormind/frontend
npm run dev
# Open http://localhost:3000 in browser

3. End-to-End Integration Tests
3.1 Test 1 — User Registration and Login
Open http://localhost:3000 in browser
Click 'Sign in with GitHub'
GitHub login page opens → Authorize the app
Redirected to /onboarding (first time) or /dashboard (returning user)
Check PostgreSQL: SELECT * FROM users; — should show your user record

3.2 Test 2 — Connect a GitHub Repository
On onboarding page: enter a public GitHub repo URL (use your own test repo)
Click 'Connect Repository'
Dashboard shows: 'Indexing... 0% complete'
Wait 2-5 minutes for a small repo to finish indexing
Dashboard shows: 'Ready — 47 items indexed'
Check ChromaDB: collection for your team should have documents

3.3 Test 3 — Ask a Question (MirrorChat)
Go to /dashboard/chat
Type: 'What is this codebase about?' and press Ctrl+Enter
AI response should stream in word by word
Below answer: source citations panel shows links to GitHub
Check PostgreSQL: SELECT * FROM queries; — should log the Q&A

3.4 Test 4 — PR Auto Review
Create a real pull request on the connected GitHub repo
Wait 60-90 seconds
Check the PR on GitHub — MirrorMind bot should have posted a review comment
Check /dashboard/review — PR should appear in the list with review details

4. Common Integration Problems and Fixes

Likely Cause
Fix
Frontend shows 'Cannot connect to API'

Ensure NEXTAUTH_URL=http://localhost:3000 in frontend/.env.local

Run: docker-compose up -d. Check docker ps shows chroma container.

Wait 30 seconds and retry. Code already has local fallback — should auto-recover.

Prisma migration error
PostgreSQL not running
Run: docker-compose up -d postgres. Wait 10 seconds. Then run migration again.

5. GitHub Webhook Local Testing with ngrok
For testing MirrorReview locally, you need to expose your backend to the internet so GitHub can send webhooks. Use ngrok (free).

Step 1 — Install ngrok: Go to ngrok.com, sign up free, download ngrok.
Step 2 — Start ngrok tunnel to backend port:
ngrok http 4000
# ngrok shows: Forwarding https://abc123.ngrok.io -> http://localhost:4000

Step 3 — Set GitHub webhook URL:
Go to your GitHub repo → Settings → Webhooks → Add webhook
Payload URL: https://abc123.ngrok.io/api/webhooks/github
Content type: application/json
Secret: the value of GITHUB_WEBHOOK_SECRET in your .env file
Which events: Select 'Pull requests' only

Step 4 — Create a PR on the repo. Within 60 seconds, MirrorMind should post a review comment.

6.2 Deploy Frontend to Vercel
Push your code to GitHub repository
Go to vercel.com — sign in with GitHub
Click 'New Project' — import your mirrormind repository
Set Root Directory to: frontend
Add environment variables (from frontend/.env.local): NEXTAUTH_SECRET, GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, NEXT_PUBLIC_API_URL (set to your Railway backend URL)
Click Deploy — Vercel builds and deploys automatically
Your frontend is now live at: https://mirrormind.vercel.app (or custom domain)

6.3 Deploy Backend + AI Service to Railway
Go to railway.app — sign in with GitHub
Click 'New Project' → 'Deploy from GitHub repo'
Select mirrormind repository
Railway auto-detects Node.js — set root to 'backend'
Add a new service in same project for Python AI service — set root to 'ai-service'
Add PostgreSQL plugin — Railway creates and connects it automatically
Add Redis plugin — same process
Add environment variables to each service (all keys from .env files)
Set NEXTAUTH_URL in Vercel to your production URL

6.4 Update GitHub OAuth App for Production
Go to github.com → Settings → Developer Settings → OAuth Apps → Your MirrorMind app
Update Homepage URL to: https://mirrormind.vercel.app
Update Authorization callback URL to: https://mirrormind.vercel.app/api/auth/callback/github

9. GitHub Copilot Prompt — Integration Build
Copy this prompt and give it to GitHub Copilot with this document.

Integrate all MirrorMind services — frontend, backend, AI service, and databases.

1. Create the final docker-compose.yml connecting all services with correct
environment variables and service dependencies (health checks).

2. Add CORS configuration to Express backend allowing frontend origin.

3. Add health check endpoints to backend (/health) and AI service (/health).

4. Create a root-level package.json with these scripts:
- 'dev': starts all 3 Node services concurrently
- 'db:up': docker-compose up -d
- 'db:migrate': cd backend && npx prisma migrate dev
- 'db:seed': cd backend && npx prisma db seed

prerequisites, environment variable setup, how to run locally,
how to deploy to Vercel + Railway.

6. Create Vercel configuration (vercel.json) for frontend deployment.
